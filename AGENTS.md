# chromahash

Modern, high-quality image placeholder representation for professional formats (LQIP).

A **monorepo** of language libraries implementing one shared format. The Rust
crate in `rust/` is the reference implementation; every other language is a thin
binding to it through an FFI surface in `bindings/`. See `README.md` for the
architecture and the full set of build commands, and `spec/` for the format.

## Hard requirements

- **`spec/` is the source of truth.** Every implementation MUST produce
  byte-identical output for the same input and pass the shared
  `spec/test-vectors/`.
- **Keep implementations in sync.** A format or API change lands in every
  language in the same change, not one language at a time. A *language-local
  ergonomic* addition is outside this rule — a helper that gives one binding
  behaviour the others already have, adding no format, no contract and no
  capability (e.g. `go.NewImageInput`, which defaults the batch tier that C#,
  Python and TypeScript already default). If it would make one binding able to
  express something another cannot, it is an API change and the rule applies.
- **The core stays zero-dependency.** `rust/` has no runtime dependencies. The
  FFI deps (`uniffi`, `cbindgen`, `wasm-bindgen`) live only in their respective
  `bindings/` crate.
- **No Cargo workspace.** The core and each binding crate are standalone — always
  pass `--manifest-path <crate>/Cargo.toml` to cargo (the mise tasks do this).
  This is deliberate; do not add a workspace.
- **Conventional commits**, enforced by the `commit-msg` hk hook and the
  `ci-commits` workflow (convco). Format `type(scope): description`; scope is one
  of `rust`, `c`, `ts`, `wasm`, `jvm`, `swift`, `go`, `py`, `csharp`, `android`,
  `uniffi`, `spec`, `tools`, `comparison`.
- **Do not hand-edit generated build outputs.** The UniFFI/wasm-bindgen-generated
  bindings (e.g. Kotlin under `bindings/uniffi/.../build/`, `typescript/wasm/`,
  `python/chromahash/_uniffi.py`) and the cross-compiled native libs are
  regenerated by the `mise run cbuild:*` / build tasks — never hand-edit or
  "restore" them.
- **Do not hand-edit the CHANGELOG `[Unreleased]` section** (between the
  `git-cliff-unreleased-*` sentinels) except to add `Removed` entries; it is
  generated by `mise run changelog`. Releases are cut with `mise run release X.Y.Z` (see
  `RELEASING.md`).

## FFI bindings (`bindings/`)

- **`bindings/uniffi/`** — UniFFI; serves Swift, Java/Kotlin (JVM JAR + Android
  AAR), and Python.
- **`bindings/c/`** — hand-written `extern "C"` + cbindgen; the first-class C API
  and the foundation for C# (P/Invoke) and Go (cgo).
- **`bindings/wasm/`** — wasm-bindgen; the encode+decode path for the TypeScript
  package.

## Conventions

- **Fail fast; validate at the boundary.** The hash is variable-length and
  self-describing, so `ChromaHash::from_bytes` validates the version, quality
  tier, reserved bits, and exact byte length, returning an error rather than
  decoding a malformed input — a hash that validates is guaranteed to decode.
  Prefer surfacing a precise error early over producing garbage downstream.
- **Rust is the reference;** the non-Rust packages are thin bindings with no
  native algorithm. Their tests are the shared spec-vector parity gate plus a
  small smoke test — not a re-implementation of the Rust suite.
- Strict **TypeScript** — no `any`. **Rust** public crates run
  `#![deny(warnings)]` once stable.
- Tooling is managed by `mise`; cross-language and per-language tasks run via
  `mise run <task>` (run `mise tasks` for the list).
